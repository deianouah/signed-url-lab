CORS Test

This page requests ping.php from the localhost origin. Open it from two different addresses and compare:

  1. http://localhost/stream-lab/cors-test.html - same origin, so CORS is not involved.
  2. http://127.0.0.1/stream-lab/cors-test.html - different origin, so the response is blocked unless it is allowed.

To make the second case succeed, add 'http://127.0.0.1' to allowed_origins in config.php, then try again. If Apache uses a port other than 80, include that port in the origin.
